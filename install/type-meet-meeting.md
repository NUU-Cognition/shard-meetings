# Meeting

A processed meeting transcript. Meetings are date-anchored and can have derivatives: raw transcripts, cleaned transcripts, and structured summaries with key decisions and action items.

## Properties

| Property | Value |
|----------|-------|
| Tag | `#meet/meeting` |
| Location | `Mesh/Types/Meetings/` |
| Archive | `Mesh/Archive/Meetings/` |
| Naming | `(Meeting) [Name] (YYYY-MM-DD).md` |
| Numbering | None (date-based) |

## Lifecycle

```
active → archived
```

- [[tmp-meet-summary-v0.2]] — Meeting summary
- [[tmp-meet-raw-v0.2]] — Raw transcript
- [[tmp-meet-cleaned-v0.2]] — Corrected transcript
